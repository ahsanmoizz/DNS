1. Consolidated decision
Daily Names remains an ENS-inspired naming protocol for .dly, .day and .daily. Daily Mail remains encrypted name-to-name 
communication. The marketing layer remains voluntary and funded in native DLY. Readable message content is encrypted before 
upload and never stored on-chain.

3. Final safe decisions in V3.6
Geography CSV: Admin can import country, state/region, city, price and optional aggregate user count. Invalid rows are 
previewed and rejected.
Pricing fallback: City pricing overrides state/region, which overrides country, which overrides global pricing.
Canonical marketer alias: Only {24-alphanumeric}.marketing.daily is used. The alternate marketing.{id}.daily form is removed.
Recipient privacy and payment safety: The application masks the resolved wallet by default but allows deliberate full 
verification before MetaMask signing.
Payment requests: Users can create a Daily payment URI, memo and QR request for another compatible wallet.
External storage: Google Drive or OneDrive can be selected as user-controlled encrypted storage. One connector is included in 
testnet production scope; the second requires separate approval.

6. External encrypted mail storage rule
Users may connect a supported user-owned storage provider such as Google Drive or OneDrive. Message bodies and 
attachments are encrypted locally before upload. The storage provider sees ciphertext only. Mailbox private keys remain on the 
user device or inside an encrypted user-controlled recovery package. The locked scope does not promise simultaneous 
production integration and maintenance of every provider.
